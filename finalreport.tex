\begin{abstract}
\noindent
This report investigates transfer learning for classifying peripheral blood cells into three classes --- red blood cells (RBCs), white blood cells (WBCs), and platelets --- using microscopy crops derived from the TXL-PBC dataset. Three ImageNet-pretrained backbones, EfficientNet-B0, MobileNetV3-Small, and DenseNet121, are compared under an identical training configuration, with class imbalance addressed through a weighted sampler and weighted cross-entropy loss. An initial evaluation reported perfect test-set accuracy, which prompted a structured data-integrity investigation rather than acceptance at face value: filename, source-image, and official split-list checks ruled out conventional leakage, while a perceptual-hash audit identified 694 near-duplicate crops (97\% RBC) that were removed before retraining. Following this cleanup, EfficientNet-B0 achieved a test macro-F1 of 1.0000, with MobileNetV3-Small and DenseNet121 close behind at 0.9952 and 0.9916 respectively. Grad-CAM visualisations provide qualitative evidence about the regions used by the model, while the varying error patterns across architectures support genuine class separability over residual leakage. The report documents this validation process alongside the standard comparison of architectures, losses, and computational cost.
\end{abstract}

\section{Introduction}

Manual microscopy for classifying blood cells is time-consuming and subject to inter-observer variability. Automated classification of red blood cells (RBCs), white blood cells (WBCs), and platelets can support haematology workflows by pre-screening microscopy fields. This report presents a transfer-learning approach to this three-class problem using the TXL-PBC dataset, comparing three convolutional backbones and addressing two practical challenges that arose during the work: class imbalance and an initially suspicious evaluation result.

The dataset used is derived from TXL-PBC, a publicly available collection of peripheral blood smear images with YOLO-format bounding-box annotations. A preprocessing pipeline crops each annotated cell, organises crops into class folders, and applies the dataset's official train/validation/test split lists. Three pretrained backbones --- EfficientNet-B0, MobileNetV3-Small, and DenseNet121 --- are fine-tuned under identical settings, with class-weighted and focal loss variants evaluated for handling the pronounced imbalance between RBC, WBC, and platelet counts.

During evaluation, all three models scored unusually high, with the best model reaching 100\% test accuracy. Rather than reporting this uncritically, a multi-stage validation process was carried out: checking for filename and source-image overlap between splits, verifying the evaluation code path, and running a perceptual-hash near-duplicate audit across every pair of splits. This process, detailed in Sections 3 and 4, is presented as a core methodological contribution of this work, alongside the architecture comparison and Grad-CAM explainability analysis.

The remainder of this report is organised as follows: Section 2 defines the dataset and the classification problem; Section 3 describes the full methodology, including preprocessing, the near-duplicate audit, model architectures, loss functions, and training configuration; Section 4 presents the experimental results, the data-integrity investigation, and Grad-CAM findings; Section 5 summarises the main conclusions.

\section{Problem Statement}

\subsection{Dataset}

The dataset originates from the TXL-PBC repository: peripheral blood smear microscopy images, each accompanied by a YOLO-format annotation file listing bounding boxes and class indices for individual cells (0 = WBC, 1 = RBC, 2 = Platelet). Each bounding box is cropped from its source image and written into a per-class folder structure (\texttt{train/}, \texttt{val/}, \texttt{test/}, each containing \texttt{RBC}, \texttt{WBC}, \texttt{Platelet} subfolders).

Splitting is performed at the \emph{source-image} level using TXL-PBC's own official split lists (882 training images, 252 validation images, 126 test images), rather than a custom random split. This preserves comparability with any other work using the same benchmark split and avoids leakage that a naive crop-level split could introduce. In practice, this yields an approximate 70/20/10 division of source images across train/validation/test --- a detail worth stating explicitly, since it differs from the commonly assumed 70/15/15 convention and was confirmed by inspecting the split-list files directly rather than assumed from a configuration comment.

The class imbalance is severe: RBCs outnumber platelets by roughly 28:1 in the test set alone. This motivates the use of macro-averaged evaluation metrics and imbalance-aware loss functions described in Section 3.

\subsection{Problem Formulation}

Given a cropped cell image \(x \in \mathbb{R}^{H \times W \times 3}\), the model outputs a probability distribution over \(C = 3\) classes:
\[
\hat{y} = \mathrm{softmax}(f_\theta(x)) \in \mathbb{R}^{C}.
\]
Because the class distribution is skewed, macro-averaged precision, recall, and F1 are used as the primary metrics rather than raw accuracy, since accuracy alone can be dominated by RBC performance while masking poor minority-class results.

\section{Proposed Method}

\subsection{Preprocessing and Data Preparation}

Raw images and YOLO labels are processed by \texttt{crop\_dataset.py}, which converts each bounding box to pixel coordinates, crops the region, discards degenerate crops, and writes the result into the class-folder structure described in Section 2. Splitting uses TXL-PBC's official image lists where present, with a seeded random 70/15/15 fallback retained in code for robustness but not active in this project's runtime, since the official lists were available.

Training-time augmentation consists of random rotation (up to \(20^\circ\)), random horizontal flipping, and brightness/contrast jitter, followed by ImageNet normalisation. Validation and test transforms apply only resizing and normalisation. A \texttt{WeightedRandomSampler} inversely weights each class by frequency so that mini-batches are approximately class-balanced during training.

\subsection{Near-Duplicate Audit and Dataset Cleaning}

An initial evaluation pass reported 100\% test accuracy for the best-performing model, which is an unusual result for a real-world microscopy dataset and was treated as a signal to investigate rather than a result to report directly. Three checks were performed before considering the number reliable:

\begin{enumerate}[itemsep=2pt]
    \item \textbf{Filename and source-image overlap.} No image filenames, and no source-image identifiers, were found duplicated across the train, validation, and test folders.
    \item \textbf{Official split-list integrity.} TXL-PBC's own train/val/test list files were checked for repeated filenames across lists; none were found, ruling out a dataset-level split flaw.
    \item \textbf{Perceptual-hash near-duplicate detection.} Since visually near-identical crops can exist between splits even without filename or source-image overlap (a known issue in microscopy datasets due to repetitive cell morphology, particularly for RBCs), a perceptual hash (pHash) was computed for every processed crop and compared pairwise across all split combinations using a Hamming-distance threshold of 5.
\end{enumerate}

The pHash audit found near-duplicate pairs across every split combination: 382 pairs between train and validation, 168 between train and test, and 42 between validation and test, for 592 pair matches in total. The subsequent clustering and cleanup removed 694 crop images while retaining one representative per near-duplicate group. The removals were heavily concentrated in RBC (675 of 694, or 97\%), consistent with the low morphological diversity of that class, with only 18 WBC and 1 Platelet image affected. Table \ref{tab:dataset} in Section 2 reports the resulting, cleaned class counts. All three models were retrained from scratch on this cleaned dataset; pre-cleaning checkpoints and results were preserved separately for comparison rather than discarded.

\subsection{Model Architectures}

Three ImageNet-pretrained backbones are compared. The implementation replaces the original ImageNet classifier with a three-class output: EfficientNet-B0 and DenseNet121 use dropout followed by a linear layer, while MobileNetV3-Small replaces its final classifier layer with a three-class linear layer. EfficientNet-B0 uses compound scaling of depth, width, and resolution \cite{tan2019efficientnet} and offers a strong accuracy-to-parameter ratio. MobileNetV3-Small \cite{howard2019mobilenetv3} is included as an efficiency baseline, while DenseNet121 \cite{huang2017densely} provides a feature-reuse baseline. The comparison therefore spans different parameter budgets and architectural designs without claiming a common custom head that is not present in the implementation.

\subsection{Loss Functions and Class Imbalance}

Two loss functions are implemented. Class-weighted cross-entropy weights each class inversely to its frequency, \(w_c \propto 1/n_c\), and is the loss selected by the project configuration. Focal loss with effective-number weighting \cite{lin2017focal,cui2019class} is available as an alternative and instead uses
\[
\mathcal{L}_{\text{focal}} = -\frac{1}{N}\sum_{i=1}^{N} \alpha_{y_i} (1 - \hat{p}_{i, y_i})^{\gamma} \log \hat{p}_{i, y_i},
\]
where \(\alpha_c\) derives from the effective number of samples \((1-\beta^{n_c})/(1-\beta)\). The reported experiments use weighted cross-entropy together with the weighted sampler; the focal-loss option was not used for the final configured runs.

\subsection{Training Configuration}

Models are optimised with Adam using a learning rate of \(3\times10^{-4}\), weight decay of \(1\times10^{-5}\), batch size 32, and a maximum of 30 epochs. Early stopping uses a patience of six epochs. Checkpoints are saved on best validation macro-F1 rather than accuracy, since accuracy alone would favour the majority RBC class. Per-epoch training time and peak GPU memory are logged automatically when available.

\subsection{Validating the Perfect-Accuracy Result}

A single perfect score would ordinarily warrant scepticism on a real dataset, so this result is validated rather than simply reported. Two pieces of evidence support its validity. First, the errors that do occur are architecture-dependent rather than uniform: if the perfect score for EfficientNet-B0 were an artefact of residual data leakage, the same leakage would be expected to inflate all three models similarly, since leakage is a property of the data pipeline, not the model. Instead, MobileNetV3-Small and DenseNet121 each make distinct, small numbers of errors, which is inconsistent with a shared leakage explanation.

Second, qualitative inspection suggests that correct predictions are not necessarily uniformly certain, which is consistent with some samples being harder than others. However, the current repository does not preserve a confidence-distribution output file, so this observation is reported as an interpretation rather than as a verified aggregate statistic. A future experiment should save per-sample probabilities before making numerical claims about the confidence distribution.

\subsection{Discussion}

EfficientNet-B0 provides the strongest result on every metric while using roughly two-thirds the parameters of DenseNet121, making it the clear recommendation from this comparison. MobileNetV3-Small, despite having under half of EfficientNet-B0's parameters, trails by only 0.0048 macro-F1, making it an attractive choice where inference efficiency matters more than the last fraction of accuracy. DenseNet121's larger parameter count did not translate into better performance here, suggesting that for this task the additional feature-reuse capacity is not the limiting factor; the RBC/WBC/Platelet distinction is dominated by size, shape and staining cues that shallower networks already capture well. This is consistent with the training-time and memory logging built into the pipeline (Section 3.5), which supports treating architecture choice here primarily as an efficiency decision rather than an accuracy one.

\section{Summary}

This report presented a transfer-learning pipeline for three-class blood cell classification, comparing EfficientNet-B0, MobileNetV3-Small, and DenseNet121 under class-imbalance-aware training. An initial perfect-accuracy result was not accepted uncritically: a structured investigation covering filename overlap, source-image overlap, official split-list integrity, and perceptual-hash near-duplicate detection identified and removed 694 near-duplicate crops before retraining. The validated result --- EfficientNet-B0 achieving a macro-F1 of 1.0000, with MobileNetV3-Small and DenseNet121 close behind --- is supported by architecture-dependent error patterns and a non-uniform confidence distribution, both inconsistent with residual leakage. Grad-CAM confirms that predictions are driven by cell morphology rather than artefacts.

This work is a research and educational exercise on a public, de-identified dataset and is not a clinical tool. Strong performance on TXL-PBC does not guarantee generalisation to different scanners, staining protocols, or patient populations, and any real deployment would require external validation, ethical approval, and secure model-loading practices beyond the scope of this project. Future work includes cross-validation for confidence intervals on macro-F1, quantitative Grad-CAM localisation against expert-annotated regions, and evaluation on an independently sourced microscopy dataset to test generalisation beyond TXL-PBC.
