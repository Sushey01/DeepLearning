\begin{abstract}
\noindent
This report investigates transfer learning for classifying peripheral blood cells into three classes --- red blood cells (RBCs), white blood cells (WBCs), and platelets --- using microscopy crops derived from the TXL-PBC dataset. Three ImageNet-pretrained backbones, EfficientNet-B0, MobileNetV3-Small, and DenseNet121, are compared under an identical training configuration, with class imbalance addressed through a weighted sampler and weighted cross-entropy loss. An initial evaluation gave EfficientNet-B0 perfect test accuracy, which prompted a data-integrity audit: filename, source-image, and official split-list checks found no conventional leakage, but a perceptual-hash audit flagged 694 crops (675 of them RBCs) as near-duplicates, 113 of them in the test split. All three models were retrained and evaluated on the cleaned dataset (1,768 test crops). EfficientNet-B0's perfect score did not survive (accuracy 0.997172, macro-F1 0.989587), and MobileNetV3-Small became the best model (accuracy 0.999434, macro-F1 0.995184) while also training fastest, ahead of DenseNet121 (0.998303 and 0.992360). The models differ by at most four test crops from single runs, so the new ranking is not statistically established and residual leakage cannot be excluded. Grad-CAM overlays are provided as qualitative examples.
\end{abstract}

\section{Introduction}

Blood cell analysis and counting support clinical diagnosis \citep{gan2025txlpbc}, and automated classification of red blood cells (RBCs), white blood cells (WBCs), and platelets could reduce the manual effort of reviewing microscopy fields. This report applies transfer learning to this three-class problem using TXL-PBC \citep{gan2025txlpbc}, a public collection that integrates four peripheral blood smear datasets, and addresses two practical challenges: severe class imbalance and an initially suspicious evaluation result.

All three models scored unusually high at first, EfficientNet-B0 reaching 100\% test accuracy. Rather than report this uncritically, the data were audited for leakage, which flagged near-duplicate crops. A cleaned dataset was built and all three models were retrained and re-evaluated on it, so the effect of cleaning could be measured directly.

The aim is to compare three pretrained backbones and to establish how far the results can be trusted. The contributions are:
\begin{itemize}[itemsep=2pt]
    \item an imbalance-aware comparison of EfficientNet-B0, MobileNetV3-Small, and DenseNet121 before and after near-duplicate removal;
    \item a data-integrity audit that flagged 694 near-duplicate crops, with an assessment of its limits and of its effect on the results;
    \item a qualitative Grad-CAM analysis of a pre-cleanup EfficientNet-B0 checkpoint.
\end{itemize}

\section{Problem Statement}\label{sec:problem}

\subsection{Dataset}

TXL-PBC \citep{gan2025txlpbc} is a curated collection integrating four public resources (BCCD, BCDD, PBC and Raabin-WBC), released under the MIT licence. It contains 1,260 smear images with 18,143 annotated cells, each image having a YOLO-format file of bounding boxes and class indices (0 = WBC, 1 = RBC, 2 = Platelet). Each box is cropped and written to per-class folders under \texttt{train/}, \texttt{val/} and \texttt{test/}.

Splitting uses TXL-PBC's official source-image lists (882 training, 252 validation and 126 test images; about 70/20/10) rather than a random split, which keeps results comparable with other work and avoids crops of one image appearing in several splits. Table~\ref{tab:dataset} gives the crop counts before near-duplicate cleanup. RBCs outnumber platelets by roughly 35:1 in the original test set and 29:1 in training (33:1 and 28:1 after cleaning), which motivates macro-averaged metrics and imbalance-aware training.

\subsection{Problem Formulation}

Given a cropped cell image \(x \in \mathbb{R}^{H \times W \times 3}\), the model outputs a probability distribution over \(C = 3\) classes:
\[
\hat{y} = \mathrm{softmax}(f_\theta(x)) \in \mathbb{R}^{C}.
\]
Because the classes are skewed, macro-F1 is the primary metric alongside accuracy, since accuracy can be dominated by RBC performance.

\subsection{Related Work and Recent Trends}\label{sec:related}

Blood cell classification is commonly studied on datasets of individual cropped cells. The PBC dataset \citep{acevedo2020pbc}, with thousands of images in eight cell groups, is widely used and is one of the four resources integrated into TXL-PBC, which adds bounding boxes for the three classes used here.

Recent work has moved towards vision transformers \citep{dosovitskiy2021vit} and modernised ConvNets such as ConvNeXt \citep{liu2022convnext}, typically pretrained at scale; these were not evaluated. Compact CNNs suit a three-class task on a modest dataset, and earlier work reports that much smaller architectures can match standard ImageNet models on medical tasks \citep{raghu2019transfusion}. MobileNetV3 \citep{howard2019mobilenetv3} targets resource-constrained devices, making it a natural efficiency baseline.

Evaluation validity is a further concern. \citet{barz2020purging} found near-duplicates between CIFAR training and test sets, \citet{kapoor2023leakage} document leakage as a common source of over-optimistic results, and \citet{geirhos2020shortcut} describe shortcut learning. \citet{adebayo2018sanity} show that some saliency methods are insensitive to model parameters, so interpretability also needs sanity checks. These points motivate the audit in Section~\ref{sec:audit} and the caution in Section~\ref{sec:validation}.

\section{Proposed Method}\label{sec:method}

\subsection{Preprocessing and Data Preparation}

All experiments use PyTorch \citep{paszke2019pytorch}; dependencies are in \texttt{requirements.txt}, and the full source is in \texttt{code.zip} (Appendix~\ref{app:repro}). \texttt{crop\_dataset.py} converts each YOLO box to pixel coordinates, discards degenerate crops and writes the class folders, using the official split lists (a random 70/15/15 fallback exists but was not used). Augmentation and the \texttt{WeightedRandomSampler} are listed in Table~\ref{tab:hyper}. Offline oversampling is configured but was not executed, so class balance relies on the sampler and loss weights alone.

\subsection{Near-Duplicate Audit and Dataset Cleaning}\label{sec:audit}

The initial 100\% test accuracy was treated as a signal to investigate. Three checks were run. First, filenames and source-image identifiers were compared across splits, and second, the official split lists were checked for repeated filenames; no overlap was found in either. Third, a perceptual hash (pHash; the default 64-bit \texttt{imagehash} hash) was computed for every crop and compared pairwise across splits, only between crops of the same class, with a Hamming-distance threshold of 5. No sensitivity analysis was run for this threshold.

The pHash audit found near-duplicate pairs in every split combination: 382 between train and validation, 168 between train and test and 42 between validation and test (592 in total, 582 involving RBCs). In total 694 crops were flagged for removal (Table~\ref{tab:dataset}), keeping the first crop of each near-duplicate group in train, validation, test order, so a duplicate in an evaluation split is removed rather than the training copy. The test set lost 113 of its 1,881 crops (6.0\%). By class, 4.1\% of RBCs, 1.4\% of WBCs and 0.2\% of platelets were flagged. Because 694 exceeds 592, some removals reflect within-split duplicates; the breakdown was not recorded.

\paragraph{Cleaned dataset and retraining.} The flagged crops were removed, leaving 12,137 training, 3,544 validation and 1,768 test crops (test: 127 WBC, 1,593 RBC, 48 platelet). All three models were retrained from their ImageNet initialisation and re-evaluated with the settings in Table~\ref{tab:hyper}; the pre-cleanup checkpoints and results were preserved separately. The two evaluations therefore use different test sets (1,881 and 1,768 crops).

\subsection{Model Architectures}

Three ImageNet-pretrained \citep{deng2009imagenet} backbones are compared (Figure~\ref{fig:architecture}): EfficientNet-B0 \citep{tan2019efficientnet}, the primary model, for its accuracy-to-size ratio; MobileNetV3-Small \citep{howard2019mobilenetv3} as an efficiency baseline; and DenseNet121 \citep{huang2017densely} as a feature-reuse baseline. Each ImageNet classifier is replaced by a three-class head (Table~\ref{tab:hyper}). Trainable parameters are approximately 4.0, 1.5 and 7.0 million respectively, derived from the standard torchvision architectures rather than measured from the checkpoints.

\subsection{Loss Function and Class Imbalance}

Imbalance is handled twice. The sampler balances mini-batches, and the loss is cross-entropy with effective-number class weights \citep{cui2019class},
\[
\mathcal{L}_{\text{WCE}} = -\frac{1}{N}\sum_{i=1}^{N} w_{y_i} \log \hat{p}_{i, y_i}, \qquad w_c \propto \frac{1-\beta}{1-\beta^{n_c}}, \quad \beta = 0.999,
\]
where \(n_c\) is the number of training crops in class \(c\) in the dataset being used, normalised so weights average about one. Focal loss \citep{lin2017focal} was implemented but not used. Because both mechanisms compensate for imbalance, minority classes are effectively corrected twice, and their separate contributions were not ablated.

\subsection{Training and Model Selection}

Models are fine-tuned with Adam \citep{kingma2015adam} (Table~\ref{tab:hyper}). Training stops when validation macro-F1 has not improved for six epochs, and the checkpoint with the best validation macro-F1 is kept, since accuracy alone would favour the majority RBC class.

\subsection{Status of the Perfect-Accuracy Result}\label{sec:validation}

The perfect score did not survive cleaning: retrained on the cleaned data, EfficientNet-B0 made five errors on 1,768 test crops. This is consistent with near-duplicates having inflated the pre-cleanup score, since the 113 removed test crops included at least some copies of training crops. It does not prove it, because each result is a single run and the training and test sets changed together, so retraining variation is confounded with the effect of cleaning. Cleaning also did not hurt every model (MobileNetV3-Small improved, DenseNet121 changed little), which fits leakage benefiting models unevenly, or run-to-run noise.

Differences between models are statistically small. Exact 95\% Clopper--Pearson intervals for the error rate are 0.09--0.66\% for EfficientNet-B0 (five errors), 0.001--0.31\% for MobileNetV3-Small (one) and 0.04--0.50\% for DenseNet121 (three). They overlap, so the new ranking is not established, and the audit's limits (Section~\ref{sec:audit}) mean the cleaned test set may still contain undetected duplicates. Three possible shortcuts were not tested: size or blur cues (small crops such as platelets are enlarged more and appear blurrier, Figure~\ref{fig:sanity}), image source (the four collections were acquired under different conditions), and prediction confidence (per-sample softmax outputs were not saved).

\subsection{Grad-CAM Explainability}

Grad-CAM \citep{selvaraju2017gradcam} was applied to the final convolutional layer of the pre-cleanup EfficientNet-B0 checkpoint. In Figure~\ref{fig:gradcam_correct}, high activation appears to fall on the nucleus for the WBC, the cell body for the RBC and the granular cluster for the platelet, not on the background. Each panel is the first test crop of its class in filename order (not chosen for representativeness), so the figure illustrates rather than establishes this behaviour. Crops are centred, so central attention is expected anyway; the maps are coarse and no saliency sanity check \citep{adebayo2018sanity} was run. Grad-CAM was generated only for this checkpoint, which is no longer the best model, so these maps say nothing about why any model made an error.

\subsection{Discussion}

After cleaning, MobileNetV3-Small was the best model, with one error, about 38\% of EfficientNet-B0's parameters and the shortest training and evaluation times, so on this dataset the smallest model was also the most accurate and efficient. EfficientNet-B0, the primary model, went from perfect to last, and DenseNet121's larger size brought no gain. The models differ by at most four crops from single runs, so these orderings are provisional and a different seed could reorder them. Timings are single-run wall-clock values, not a controlled latency benchmark.

\section{Summary}\label{sec:conclusion}

\subsection{Study Overview}

This report compared EfficientNet-B0, MobileNetV3-Small and DenseNet121 for three-class blood cell classification on TXL-PBC under imbalance-aware training, and treated an initial perfect test score as a prompt for investigation rather than a result to report as-is. Filename, source-image and split-list checks found no conventional leakage, but a perceptual-hash audit flagged 694 near-duplicate crops, and all three models were retrained and re-evaluated on the cleaned dataset so the effect of the cleaning could be measured directly rather than assumed.

\subsection{Main Findings}

On the cleaned test set (1,768 crops), MobileNetV3-Small was the best model (accuracy 0.999434, macro-F1 0.995184) and also the fastest to train (895.60~s), ahead of DenseNet121 (0.998303, 0.992360) and EfficientNet-B0 (0.997172, 0.989587). EfficientNet-B0's pre-cleanup perfect score did not survive retraining on the cleaned data, and cleaning reversed the model ranking: the smallest model tested became the most accurate. Differences of one to four errors between models fall within overlapping 95\% confidence intervals, so this ranking is indicative rather than statistically established.

\subsection{Data-Integrity Findings}

The near-duplicate audit is the report's central methodological result: 694 crops (675 of them RBCs) were flagged across every split-pair combination, 113 of them in the test split, despite the dataset using official source-image-level splits. This shows that a split at the image level does not guarantee crop-level independence when the underlying collections themselves may overlap, and that an unusually strong result is itself evidence worth checking before it is reported.

\subsection{Explainability}

Grad-CAM overlays on the pre-cleanup EfficientNet-B0 checkpoint placed high activation on plausible regions (the nucleus for WBCs, the cell body for RBCs, the granular cluster for platelets) rather than on the background, offering a qualitative, illustrative check consistent with the model attending to the cell rather than to artefacts. No saliency sanity check was run and no map was produced for the retrained, better-performing models, so this evidence is suggestive only.

\subsection{Limitations}

Every result is a single run at a fixed seed, with error-rate confidence intervals that overlap across models. The pHash audit cannot detect flipped or rotated duplicates and compared crops within class only, so some residual leakage in the cleaned test set cannot be ruled out, and the pre- and post-cleanup evaluations use different test sets, which complicates direct comparison. Grad-CAM was applied to one checkpoint that is no longer the best model, and training/evaluation timings are single-run wall-clock figures rather than a controlled benchmark.

\subsection{Future Work}

Repeating each model across several seeds, or using grouped cross-validation, would let the current ranking be tested statistically rather than read off single runs. Hashing at source-image level (rather than per-crop) and auditing for leakage before the first training run, rather than after an unusually strong result, would avoid a full retraining cycle and give the split process the earlier scrutiny it needed here. Re-running Grad-CAM with a parameter-randomisation sanity check on the retrained models, saving per-sample predictions, and testing on an independent microscopy dataset would each add evidence this report currently lacks.

\subsection{Practical and Ethical Considerations}

This is an educational exercise on a public dataset, not a clinical tool. Misclassifying platelets as white cells, or the reverse, could distort automated cell counts, and any real diagnostic use would require external validation on independent patient data, ethical approval, and review by a qualified clinician. Because the four collections integrated into TXL-PBC were acquired under different conditions, results here should not be assumed to transfer to other scanners, staining protocols or patient populations without further testing.

\section{Reproducing the Pipeline}\label{app:repro}

The full project, including the configuration file and requirements, is supplied as \texttt{code.zip} with this report (Table~\ref{tab:code}); source listings are not reproduced here. Results before and after cleaning were written to separate folders (\texttt{outputs\_pre\_dedup/} and \texttt{outputs\_post\_dedup/}). The commands below reproduce the pipeline.

\begin{table}[H]
\centering
\caption{Contents of the code archive.}
\label{tab:code}
\begin{tabular}{|>{\raggedright\arraybackslash}p{7.6cm}|>{\raggedright\arraybackslash}p{7.2cm}|}
\hline
\textbf{File} & \textbf{Purpose} \\
\hline
\texttt{src/crop\_dataset.py} & Crops annotated cells and builds the class folders \\
\hline
\texttt{src/deduplicate\_processed\_dataset.py} & pHash near-duplicate audit and removal \\
\hline
\texttt{src/train.py} & Model construction, sampler, loss and training loop \\
\hline
\texttt{src/evaluate.py} & Test-set evaluation and metrics \\
\hline
\texttt{src/plot\_model\_results.py} & Comparison figures \\
\hline
\texttt{src/gradcam.py} & Grad-CAM overlays \\
\hline
\texttt{configs/config.yaml} & Hyperparameters and paths \\
\hline
\texttt{requirements.txt} & Python dependencies \\
\hline
\end{tabular}
\end{table}

\begin{lstlisting}[numbers=none,caption={End-to-end commands}]
# 1. Install dependencies
pip install -r requirements.txt

# 2. Build cropped dataset from raw images + YOLO labels
python src/crop_dataset.py --config configs/config.yaml

# 3. Audit near-duplicate crops (dry run; writes the audit summary)
python src/deduplicate_processed_dataset.py

# 4. Train and evaluate on the original splits (pre-cleanup results)
python src/train.py --config configs/config.yaml --model efficientnet_b0
python src/train.py --config configs/config.yaml --model mobilenet_v3_small
python src/train.py --config configs/config.yaml --model densenet121
python src/evaluate.py --config configs/config.yaml --model all
python src/plot_model_results.py --config configs/config.yaml

# 5. Remove the flagged crops, then repeat step 4 with the output
#    folders set to a separate location (post-cleanup results)
python src/deduplicate_processed_dataset.py --apply

# 6. Generate Grad-CAM overlays
python src/gradcam.py --config configs/config.yaml --model efficientnet_b0
\end{lstlisting}
